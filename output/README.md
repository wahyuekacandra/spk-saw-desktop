# Output Folder

Folder ini berisi hasil export laporan perhitungan SAW dalam format text file (.txt).

## Format File
File yang dihasilkan berisi:
1. Informasi tanggal dan waktu export
2. Daftar kriteria (kode, nama, bobot, jenis)
3. Daftar alternatif
4. Nilai asli setiap alternatif untuk setiap kriteria
5. Matrix normalisasi
6. Hasil ranking final dengan nilai preferensi

## Nama File
Format: `Hasil_SAW_YYYYMMDD_HHMMSS.txt`
- YYYY: Tahun
- MM: Bulan
- DD: Tanggal
- HH: Jam
- MM: Menit
- SS: Detik

## Cara Menggunakan
1. Buka aplikasi SPK-SAW
2. Lakukan perhitungan ranking di tab "Hasil & Ranking"
3. Klik tombol "📄 Export ke PDF"
4. File akan tersimpan otomatis di folder ini
