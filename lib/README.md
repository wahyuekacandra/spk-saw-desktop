# Library Dependencies

## Gson Library

Download Gson dari Maven Repository:
https://repo1.maven.org/maven2/com/google/code/gson/gson/2.10.1/gson-2.10.1.jar

Simpan file `gson-2.10.1.jar` ke folder ini.

Atau download langsung:
```
wget https://repo1.maven.org/maven2/com/google/code/gson/gson/2.10.1/gson-2.10.1.jar
```

## JavaFX SDK

Download JavaFX SDK dari:
https://gluonhq.com/products/javafx/

Extract dan simpan path-nya untuk digunakan saat compile dan run.
